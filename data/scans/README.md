# Training Data

Each subfolder is one scan used for fine-tuning RoomFormer.

```
data/scans/
  living_room_01/
    cloud.ply         ← dense point cloud (from COLMAP or LiDAR)
    floor_plan.json   ← ground truth annotation (saved from the browser)
    density.png       ← auto-generated by: python fp.py prep
```

## Adding a new scan

1. Record a room walkthrough video on your phone
2. `python fp.py dense room_video.mp4`  → generates `cloud.ply`
3. Drop `cloud.ply` into the floor plan tab in the browser
4. Click "Generate from PLY" → adjust any rooms that are wrong
5. Click "Save JSON" → save as `floor_plan.json` in the same folder
6. `python fp.py prep`  → generates `density.png`
7. `python fp.py train` → fine-tunes the model, downloads checkpoint

The more scans you add, the better the model gets.
